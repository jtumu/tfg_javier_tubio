# tfg_javier_tubio
This repository contains the scripts used to randomize the proteomes and analyze the data given by FANTASIA. 

The script named "Análisis_csv.R" is a R script ready to read the .csv files that FANTASIA Lite generates with all the information. 

The script named "Aleatorizador_copia.py" is the Python script used to scramble the order of the aminoacids in the proteins of a proteome.
